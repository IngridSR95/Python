# 🐍 Estudos em Python

Bem-vindo(a) ao meu repositório de estudos com a linguagem Python! 🚀  
Aqui você vai encontrar pequenos projetos, exercícios e anotações que venho desenvolvendo enquanto aprendo e aprofundo meus conhecimentos.

## 🧠 Sobre

Este repositório foi criado com o objetivo de reunir tudo o que venho praticando com Python — desde os fundamentos até conceitos mais avançados, de forma simples, prática e descomplicada. Cada diretório representa uma etapa da minha jornada de aprendizado.

Todos os conteúdos e desafios de códigos desenvolvidos durante as aulas da plataforma DIO, bem como exercícios e desafios de Python desenvolvidos nos cursos do Coletivo Mirtha Lina - UFABC, estão disponíveis neste repositório.

## 📁 Estrutura do repositório

- `DesafiosDIO/` — Desafios de Python realizados durante o curso da plataforma DIO.
- `Exercicios/` — Exercícios variados focados em diferentes conceitos e práticas de Python.
- `UfabcMinas/` — Exercícios do Curso de Python UFABC para Min@s.
